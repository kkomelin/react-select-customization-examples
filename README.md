# React Select Customization Examples

Code examples for the [Developing a Custom Search Box With React-Select](https://komelin.com/blog/developing-custom-search-box-with-react-select) tutorial.

## Play locally

Clone the project and run:

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:5173](http://localhost:5173) in the browser.

## Check out the hosted version

Open [https://react-select-customization-examples.vercel.app/](https://react-select-customization-examples.vercel.app/)
